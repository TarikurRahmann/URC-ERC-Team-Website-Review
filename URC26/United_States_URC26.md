## সামগ্রিক ফল

যুক্তরাষ্ট্রের তালিকায় একই ধরনের ৩৯টি team website নেই। এর মধ্যে রয়েছে শক্তিশালী স্বতন্ত্র engineering site, university project page, বৃহত্তর robotics-club landing page, social profile এবং এমন link যেগুলো review-তে আর content দেখায়নি। এ কারণে score-গুলো public presentation-এর—দলের rover performance বা URC result-এর নয়। LinkedIn/Instagram-নির্ভর উপস্থিতির score-ও website-design score হিসেবে পড়া উচিত নয়।

বর্তমান প্রতিযোগিতা ও rover engineering-কে সবচেয়ে ভালোভাবে একসঙ্গে দেখায় **Team Mountaineers**, **MRover**, **Cornell Mars Rover**, **Husky Robotics**, **SC Robotics**, **A.S.T.R.A.**, **DAM Robotics**, **RoboNav** ও **UMD Loop**। এদের সাইটে ২০২৬ rover/SAR, সাম্প্রতিক দলীয় update, পুরোনো iteration বা subsystem-সংক্রান্ত উপাদান আছে। অন্যদিকে BYU, MAVRIC ও RIT SPEX-এর প্রকাশ্য page-এ মূলত পুরোনো season-এর তথ্য; আর কয়েকটি তালিকাভুক্ত link আসলে সাধারণ robotics club বা university directory, যেখানে URC team-টির পরিচয় ও engineering detail কম।

**স্কোর-পদ্ধতি:** রেটিংযোগ্য প্রতিটি presence-কে দশটি সমান-ওজনের দিক—নকশা, বিষয়বস্তুর স্পষ্টতা, তথ্যের ক্রম, navigation, mobile evidence, বিশ্বাসযোগ্যতা/সতেজতা, contact/CTA, accessibility, URC26-প্রাসঙ্গিকতা এবং engineering presentation—মিলিয়ে এক দশমিক স্থানে composite score দেওয়া হয়েছে। ৩৯টি entry-র জন্য আলাদা দশ-সারি score table দিলে একই সীমিত mobile/WCAG প্রমাণকে অতিরঞ্জিত করা হতো; তাই প্রতিটি দলের score-এর সঙ্গে সেই score-এর পক্ষে থাকা প্রকাশ্য evidence এবং প্রধান gap দেওয়া হয়েছে। যথেষ্ট content না পাওয়া গেলে score বাদ রাখা হয়েছে।

## যে common উন্নয়নগুলো বেশি কাজে দেবে

1. **URC26 evidence-কে সামনে আনা:** Current team status, qualification/SAR, finals result, score source ও post-competition lessons learned এক জায়গায় রাখুন। “2027 upcoming” লেখা থাকলে ২০২৬-এর ফল আড়াল করবেন না।
2. **একটি dedicated rover page:** বৃহত্তর Robotics Club, university project page বা social profile হলে rover team-এর নিজস্ব mission, member role, subsystem, rover version ও contact path আলাদা করে দিন।
3. **Claims-এর পাশে source:** Team site-এ প্রকাশিত rank, award, score, team size বা rover metric-কে official result sheet, event page বা dated report-এর link দিয়ে যাচাইযোগ্য করুন।
4. **Update-এর তারিখ স্পষ্ট করা:** ২০২৩/২০১৮-এর পুরোনো objective থাকলে archive label দিন; current recruitment deadline ও upcoming event copy সময়মতো পরিবর্তন করুন।
5. **Accessibility ও mobile:** Meaningful image alt, named controls, pause/reduced-motion options, keyboard-accessible navigation এবং ৩২০–৩৯০px viewport-এ real check দরকার। এই review-তে প্রত্যেক site-এ পূর্ণ WCAG/mobile test করা হয়নি।
6. **Fallback:** Notion, Google Sites, club directory বা JavaScript SPA-তে content যদি crawler/anonymous browser-এ না আসে, basic team intro ও key links-সহ static public landing page রাখুন।
